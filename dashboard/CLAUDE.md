# dashboard

Part of **relic** — see the [root CLAUDE.md](../CLAUDE.md) for project-wide rules, and its "Dashboard" section under Conventions for this app's component layout, package manager, and styling choices.

Two things that bite here specifically:

- **This Next.js is not the one you know.** 16.3 with React 19.2; APIs and file structure differ from older versions. The authoritative reference is `node_modules/next/dist/docs/` — read it rather than writing from memory. That is what the generated block above is warning about.
- **The `nextjs-agent-rules` block in [AGENTS.md](AGENTS.md) is regenerated by `next dev`.** Deleting it only recreates it as an uncommitted change. Leave it alone and commit it with your work.

This app reads the relic API and renders the live session feed. It never talks to DynamoDB, Kinesis, or S3 directly — only the HTTP API. The PII rules in the root CLAUDE.md apply to anything rendered here: game logs carry real player identifiers, so nothing from a session goes into a commit, an issue, or an external service.
